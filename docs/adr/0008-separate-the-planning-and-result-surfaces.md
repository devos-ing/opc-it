# Separate the planning and result surfaces

Codex Desktop will be the only interactive surface for grilling, plan review, and Plan Approval. GitHub Issues will act as the unattended queue and audit record, while GitHub will surface only a Delivery Pull Request or Terminal Blocker as an Attention Event after execution starts. Version one will not add Slack, email, or a custom dashboard; this accepts dependence on two existing products in exchange for minimizing owner monitoring and avoiding another interface to build and operate.
