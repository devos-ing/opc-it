# Bound execution and notify only for decisions

Version one will enforce an Execution Envelope of ninety minutes per execution, fifteen minutes per independent Result Review, three total execution attempts, and one hundred megabytes per Evidence Bundle. Repositories and milestones may lower but never raise these limits. Each attempt records duration, model version, available token usage, state transitions, and artifact hashes. Routine progress, Run Incidents, and Recovery Issues remain in Actions summaries, checks, labels, and unassigned records; only Plan Approval or reapproval, Delivery Pull Request review, Needs Decision, and Terminal Blocker become Attention Events. This reduces continuous visibility and permits delayed awareness of intermediate trouble in exchange for protecting the owner's time while retaining an auditable record.
